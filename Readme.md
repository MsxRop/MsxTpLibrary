# MSXTPLibrary

Open-source Turbo Pascal 3.01 library for MSX computers.

The goal of this project is to provide a simple and consistent interface between Borland Turbo Pascal 3 and the MSX BIOS.

Current status: Beta 1.0

## Features

- BIOS access routines
- VDP support
- VRAM read/write functions
- Sprite management
- Keyboard support
- Joystick support
- Mouse support
